# مزاد أبو شادن

موقع مستقل تماماً عن «مزاد سوم». نسخة من نفس المحرّك، والفروق كلها مجمّعة
في أعلى `index.html` عشان يبقى الملفان قابلين للمزامنة.

## كيف ينتشر

مشروع **Vercel منفصل** على نفس المستودع، مع ضبط:

| الإعداد | القيمة |
|---|---|
| Root Directory | `abushadan` |
| Framework | Other |
| Build Command | (فاضي) |
| Output Directory | `.` |

بعدها يُربط الدومين من لوحة Vercel. `mazad.html` في جذر المستودع لا يتأثر
بأي نشر من هنا.

## ما الذي يختلف عن «مزاد سوم»

1. **الهوية** — الاسم، الشعارات، و«ش» في الشارة.
2. **الألوان** — أسود `#090909` وذهبي `#bd7803` وكريمي `#e6d09f`، وكلها
   **مقاسة من شعاره** لا مختارة بالعين: ذهب الشعار كله على درجة 37°.
3. **بطاقة البث سوداء صريحة بلا تدرّج** («اسود كامل بدون تدرج») — عكس
   بطاقة مزاد سوم المتدرّجة من العنابي للزيتي.
4. **العمولة** — قاعدة واحدة على القسمين: 300 ثابتة و1.5% فوق 20,000.
   الرقمان متوافقان (20,000 × 1.5% = 300) فلا تقفز العمولة عند الحد.
5. **`NOTE_KINDS`** — خانة ملاحظات للسيارات، تُعرض في صفحة السيارة.
6. **`SITE_URL`** — العنوان الذي يُقرأ على بطاقة البث. كان **مكتوباً
   بالثابت**، فكانت نسخة الموقع تعرض دومين المالك الأصلي على بث غيره.

## ناقص قبل التشغيل للناس

- [ ] **مشروع Supabase خاص بأبو شادن** — يُفتح بحسابه هو، ثم تُشغّل عليه
      `supabase-mazad.sql` كما هي، ويوضع الرابط والمفتاح العام في أعلى
      `index.html`. وهما فاضيان الآن، فالموقع يعمل **وضع تجريبي** على
      `localStorage` — يُعرض ويُجرّب بالكامل بدون قاعدة بيانات.
- [ ] **إضافة رابط مشروعه في `connect-src`** داخل `vercel.json` (https و wss)،
      وإلا حجب المتصفح كل طلب.
- [ ] **كلمة سر المشرف** — تُكتب في `mazad_config.admin_secret` عنده، وتكون
      ملكه هو.
- [ ] **الدومين** — باسمه وبحسابه وبطاقته.
