# تشغيل فريق رفد المحاسبي على السيرفر — الخطوات كاملة

## قبل البدء: جهّزي 3 مفاتيح
1. **رمز بوت تيليجرام**: في تيليجرام افتحي `@BotFather` ← أرسلي `/mybots` ← اختاري `RafdAccountingTeamBot` ← **API Token**.
2. **مفتاح Claude API**: موقع `console.anthropic.com` ← سجّلي ← **Billing** أضيفي بطاقة ورصيد (يكفي 10–20 دولار للبداية) ← **Limits** حطي حدًا شهريًا ← **API Keys** ← **Create Key** وانسخيه (يبدأ بـ `sk-ant-`).
3. **مفتاح دفترة**: حساب `rafd1.daftra.com` ← الإعدادات ← **API** ← انسخي المفتاح.

لا ترسلي أيًّا منها في تيليجرام أو أي محادثة.

## 1) افتحي نافذة الأوامر
لوحة UltaHost ← السيرفر ← **Xterm.js Console** (وليس noVNC: Xterm يقبل اللصق، noVNC غالبًا لا).
- اسم المستخدم: `root`
- كلمة المرور: كلمة مرور السيرفر من إيميل UltaHost. إن لم تعرفيها: زر **Change Password** في نفس الصفحة.
- الكتابة لا تظهر وأنتِ تكتبين كلمة المرور — طبيعي. اضغطي Enter.

## 2) الصقي هذا الأمر واضغطي Enter
```
curl -fsSL https://raw.githubusercontent.com/giggz2019-beep/rafd-farz/accounting-agents/accounting-agents/deploy/server-setup.sh -o setup.sh && sudo bash setup.sh
```
اللصق في Xterm: زر الفأرة الأيمن ← Paste، أو `Ctrl+Shift+V`.
ينتظر عدة دقائق وهو يثبّت.

## 3) مفتاح GitHub
يطبع سطرًا طويلًا يبدأ بـ `ssh-ed25519`. انسخيه كاملًا ثم:
GitHub ← المستودع `rafd-farz` ← **Settings** ← **Deploy keys** ← **Add deploy key**
- Title: `rafd-accounting-server`
- Key: الصقي السطر
- **لا** تضعي صحًا على *Allow write access*
- **Add key**، ثم ارجعي للسيرفر واضغطي **Enter**.

## 4) المفاتيح الثلاثة
يطلبها واحدًا بعد الآخر. الصقي كل مفتاح واضغطي Enter (لا يظهر على الشاشة — طبيعي).

## 5) النهاية
- يظهر **«✅ تم. البوت شغّال»** ← أرسلي للبوت في تيليجرام أي رسالة. يرد «وصلت ✅» خلال ثوانٍ، ثم يرد بالجواب.
- إن ظهر **«رمز البوت غير صحيح»**: شغّلي `sudo bash setup.sh` مرة ثانية وأعيدي إدخال الرمز (Enter على الباقي يبقيه كما هو).
- إن ظهر **«❌ الخدمة لم تعمل»**: صوّري الشاشة كلها واحفظيها لجلسة الإصلاح.

## أوامر مفيدة لاحقًا (في نفس النافذة)
| الغرض | الأمر |
|---|---|
| هل يعمل؟ | `systemctl status rafd-bridge` |
| آخر ما حدث | `journalctl -u rafd-bridge -n 50 --no-pager` |
| إعادة تشغيل | `systemctl restart rafd-bridge` |
| إيقاف مؤقت | `systemctl stop rafd-bridge` |
| تغيير مفتاح | `sudo bash setup.sh` ثم Enter على ما لا تريدين تغييره |

## بعد التشغيل
- **حوّلي المستودع إلى خاص**: GitHub ← `rafd-farz` ← Settings ← General ← Danger Zone ← Change visibility ← Private. التحديثات تستمر.
- **الموظف ينفّذ** الروتيني (أسئلة، تقارير، فواتير واضحة ≤ 1,000 ريال) ويؤكد بسطر، و**يسألك «نعم / لا»** في: أكثر من 1,000، مورد جديد، عقد، تعديل قيد، رواتب وتأمينات وضريبة، وأي شيء عليه توقيعك. ولا يدفع ولا يغيّر بيانات بنكية أبدًا.
- لا تفتحي جلسة Claude Code تفحص تيليجرام بنفس الوقت — تسرق الرسائل من السيرفر.
