# ترند الرياض — نموذج أولي (PWA)

موقع/تطبيق تصفّح يجمع **كل شيء في الرياض** في مكان واحد، بأقسام متفرعة وبحث بالاسم وتقييمات قوقل الحيّة.

الفرق عن انستقرام وتيك توك: هنا تفتح القسم، تختار الفرع، تلقى المكان بالاسم، تشوف تقييمه في قوقل، وتضغط الاتجاهات. بدون ما تنزل في فيديوهات.

## الأقسام (13 رئيسي، 71 فرعي)

للشباب · للبنات · صحة وجمال · كافيهات · مطاعم · حلويات · وجهات وسكويرات · أسواق ومولات · أطفال · شاليهات واستراحات · قاعات وأفراح · فنادق · فعاليات

كل قسم له أقسام فرعية (مثل: للشباب › ديوانيات شاي، أكاديميات كرة، بدل وثياب…). القائمة كاملة في أعلى `places.js`، وتعديلها لا يحتاج لمس الكود.

## ثلاثة أنواع من الأماكن

| النوع | الحقل | كيف يظهر |
|---|---|---|
| ترند | `trend: true` | شارة 🔥 وشريط "ترند الآن". قرار المشرف فقط، **لا يُباع** |
| مدفوع / شريك | `sponsored: true` | شارة "إعلان" وقسم "أماكن مميزة". لا يدخل الترند أبدًا حتى لو `trend: true` |
| بتوصية | `recommendedBy: 'اسم'` | "👍 بتوصية من …" على البطاقة (أساس نظام النِسَب للموصين) |

## تقييمات قوقل

- سياسة قوقل (موثقة في [شروط Places API](https://developers.google.com/maps/documentation/places/web-service/policies)): يُسمح بتخزين **Place ID** فقط. التقييم وعدد المقيّمين والمراجعات يجب أن تُطلب حيّة وتُعرض مع نسب "Google".
- لذلك: كل مكان يحمل `placeId`، والتقييم يُجلب عند فتح صفحة المكان عبر `api/trend-riyadh-place.js` (دالة Vercel) بمفتاح `GOOGLE_MAPS_API_KEY`.
- بدون مفتاح، أو إذا لم يكن للمكان `placeId`: يظهر زر "التقييم في خرائط قوقل" بدل الأرقام. لا شيء ينكسر.
- **التكلفة** (تحقّق من [صفحة الأسعار](https://developers.google.com/maps/documentation/places/web-service/usage-and-billing)): التقييم وعدد المقيّمين ≈ 35$ لكل 1000 طلب بعد 1000 طلب مجانية شهريًا. المراجعات النصية أغلى (≈ 40$/1000) وتُطلب فقط بإضافة `&reviews=1`. لهذا التقييم يُجلب عند فتح المكان وليس على كل البطاقات.

### تفعيل التقييمات (10 دقائق)

1. Google Cloud Console → مشروع جديد → فعّل **Places API (New)** → أنشئ مفتاح API وقيّده على Places API فقط.
2. Vercel → Environment Variables → `GOOGLE_MAPS_API_KEY`.
3. لجلب `placeId` لكل الأماكن دفعة واحدة:
   ```bash
   GOOGLE_MAPS_API_KEY=xxx node trend-riyadh/tools/find-place-ids.js          # عرض فقط
   GOOGLE_MAPS_API_KEY=xxx node trend-riyadh/tools/find-place-ids.js --write  # كتابة داخل places.js
   ```
   يستخدم أرخص نوع بحث (IDs Only). راجع النتائج: البحث بالاسم قد يرجّع فرعًا آخر.

## التشغيل

- محليًا: `python3 -m http.server 3000` من جذر المستودع ثم افتح `/trend-riyadh/`. (التقييمات تحتاج `vercel dev` مع المفتاح.)
- على Vercel: يُنشر مع الموقع الحالي على `/trend-riyadh/`. للنشر كموقع مستقل بدومين خاص: انقل المجلد + `api/trend-riyadh-place.js` إلى مستودع جديد.

## الملفات

| الملف | الدور |
|---|---|
| `index.html` | التطبيق كاملًا: الأقسام، البحث، الفلاتر (الجمهور/المنطقة/السعر)، صفحة المكان، تقييم قوقل، المفضلة، نموذج التوصية |
| `places.js` | الأقسام والأماكن — يعدّله المشرف يدويًا في المرحلة الأولى |
| `../api/trend-riyadh-place.js` | جلب تقييم قوقل لمكان واحد |
| `tools/find-place-ids.js` | يجلب Place ID لكل مكان |
| `supabase-places.sql` | مخطط المرحلة الثانية |
| `manifest.webmanifest`, `sw.js` | التثبيت على الجوال والعمل بدون إنترنت. غيّر `CACHE` في `sw.js` عند كل تحديث |

## إضافة مكان

انسخ أي كائن في `places.js` وعدّله. ثلاث قواعد:
1. `id` فريد بحروف إنجليزية.
2. `sec` و `sub` من القائمة أعلى الملف (وإلا لن يظهر في قسمه).
3. `verified: true` فقط بعد التأكد أن المكان يعمل والعنوان صحيح.

الإدخالات التي تحمل `demo: true` توضيحية لعرض شكل الأقسام، احذفها أو استبدلها قبل النشر.

## الإعدادات

في أعلى `<script>` داخل `index.html`:
```js
const CONFIG = { whatsapp: '', email: '', newDays: 45, ratingsApi: '../api/trend-riyadh-place' };
```
بدون رقم أو بريد، نموذج "أضف توصيتك" ينسخ التوصية للحافظة فقط.

## المرحلة الثانية (بعد امتلاء البيانات)

1. Supabase: شغّل `supabase-places.sql`، ثم استبدل `places.js` بـ `fetch` من `places_public`.
2. لوحة إدارة: إضافة/تعديل الأماكن، مراجعة التوصيات، تفعيل الشركاء المدفوعين.
3. نظام الموصين: كل موصٍ له كود؛ رابط المكان يحمل `?ref=كود`؛ جدول `place_clicks` يعدّ الزيارات؛ النسبة تُحسب من الإعلانات المرتبطة بالمكان.
4. صور الأماكن (`image_url`).
5. المتاجر: تغليف الـ PWA بـ Capacitor عند الحاجة.
