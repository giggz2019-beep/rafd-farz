# دليل الرياض — نموذج أولي (PWA)

تطبيق ويب خفيف يجمع ترندات الرياض في مكان واحد: كافيهات، مطاعم، حلويات، وجهات وسكويرات، أسواق، محلات شباب وبنات، صالونات، أطفال، شاليهات، فنادق، فعاليات.

يعمل كتطبيق قابل للتثبيت على الجوال (PWA) بدون متاجر التطبيقات، ويشتغل بدون إنترنت بعد أول فتح.

## التشغيل

- محليًا: أي خادم ملفات ثابتة على مجلد المستودع ثم افتح `/riyadh-guide/`. مثال: `python3 -m http.server 3000`.
- على Vercel: المجلد يُنشر تلقائيًا مع الموقع الحالي على المسار `/riyadh-guide/`. لنشره كتطبيق مستقل، انقل المجلد إلى مستودع خاص به واربطه بمشروع Vercel جديد بنفس الإعدادات (Framework = Other، بدون build).

## الملفات

| الملف | الدور |
|---|---|
| `index.html` | التطبيق كاملًا: الواجهة، البحث، الفلاتر، صفحة المكان، المفضلة، نموذج "أضف مكان" |
| `places.js` | قاعدة بيانات الأماكن (المرحلة الأولى — ملف واحد يعدّله المشرف يدويًا) |
| `manifest.webmanifest` | بيانات التثبيت على الجوال |
| `sw.js` | التخزين للعمل بدون إنترنت. غيّر `CACHE` عند كل تحديث حتى يصل التحديث للمستخدمين |
| `supabase-places.sql` | مخطط قاعدة البيانات للمرحلة الثانية (لوحة إدارة + اقتراحات المستخدمين) |

## إضافة مكان (المرحلة الأولى)

افتح `places.js`، انسخ أي كائن، وعدّل الحقول. التعليق في أعلى الملف يشرح كل حقل. أهم ثلاث قواعد:

1. `id` فريد وبحروف إنجليزية.
2. `addedAt` بتاريخ اليوم — التطبيق يضع شارة "جديد" تلقائيًا لمدة 45 يوم.
3. `verified: true` فقط بعد التأكد من العنوان وأن المكان ما زال يعمل.

الإدخالات التي تحمل `demo: true` توضيحية فقط ويجب حذفها أو استبدالها قبل النشر.

## إعدادات سريعة

في أعلى `<script>` داخل `index.html`:

```js
const CONFIG = {
  whatsapp: '',   // رقم استقبال الاقتراحات بصيغة دولية بدون +
  email: '',      // أو بريد بديل
  newDays: 45,
};
```

بدون رقم أو بريد، نموذج "أضف مكان" ينسخ الاقتراح إلى الحافظة فقط.

## الطريق للمرحلة الثانية

1. **قاعدة بيانات**: شغّل `supabase-places.sql` في Supabase، ثم استبدل `places.js` بطلب `fetch` من جدول `places` (قراءة عامة عبر RLS).
2. **لوحة إدارة**: صفحة محمية بكلمة مرور لإضافة الأماكن ومراجعة اقتراحات المستخدمين (`place_suggestions`).
3. **صور**: حقل `image_url` جاهز في الجدول — استخدم Supabase Storage أو روابط انستقرام.
4. **الفعاليات**: حقل `ends_at` يخفي الفعالية تلقائيًا بعد انتهائها.
5. **المتاجر**: عند الحاجة لوجود في App Store / Google Play، غلّف الـ PWA بـ Capacitor بدون إعادة كتابة.

## ما لا يفعله هذا النموذج بعد

- لا يجلب "الترند" تلقائيًا من انستقرام أو تيك توك — الترند قرار بشري يضعه المشرف (`trend: true`).
- لا يعرض صور الأماكن (خلفيات لونية بحسب التصنيف).
- لا يحفظ المفضلة عبر الأجهزة (localStorage فقط).
